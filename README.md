# Virtual Pet Simulator

A C++ console-based virtual pet game where users can feed, play with, and care for their digital pet.

## Description

This is a semester project that simulates a virtual pet with real-time stats including:
- **Hunger** - Feed your pet to keep it from starving
- **Happiness** - Play with your pet to keep it happy
- **Energy** - Let your pet sleep to restore energy

If stats drop too low, your pet gets sick or dies!

## Features

- Feed, play, and sleep actions
- Pet stats update in real-time
- Pet ages over time
- Multiple pet types (Dog, Cat, Dragon)
- Save and load game progress
